ALL-AUTO OPERATIONS

What runs without you

Adaptive polling

45-second refresh during live scoring and 10-minute refresh between deadlines. Tabs pause polling when hidden.

Stale-while-revalidate cache

The API keeps a last-good response in memory and ships a committed snapshot for cold starts or upstream outages.

Scheduled data refresh

A GitHub Actions workflow regenerates the offline snapshot and commits it without manual intervention.

Installable PWA

A service worker caches the app shell and falls back to the snapshot when the user goes offline.

# FPL VORTEX direction

Applied Replica design and design-taste-frontend's app-screen workflow. Draw seed 756949003 selected Framed sheet, retaining the established emerald/gold brand and choosing self-hosted Manrope under the included OFL licence.

On this screen, the crowned lion's emerald and gold become a matchday research sheet: a prominent squad pitch, compact fixture ledger and restrained team projections. The reference images supply the information hierarchy. No reference logos, assets, proprietary fonts or component code were copied.

The original lion remains uncropped. Labels use shared tokens, numbers use tabular figures, sort buttons show direction and theme controls expose their pressed state. The requested two-colour gradient appears only in comparison bars; this is a deliberate exception to the app skill's flat-colour default. Table colouring is optional and never removes the numerical value.

Shared primitives: 36px primary/secondary buttons, 32px segmented controls, 10px panel corners, 14px grid gaps, 52px topbar and 184px desktop navigation. Desktop uses three primary columns; tablets stack the pitch before fixtures/projections; mobile uses a horizontal navigation strip and one content column. Tables scroll inside their panels.

Native browser QA replaces the skill's Chromium inspector because this environment requires its supported browser control. Checked rendered desktop and 390/768px iframe viewports, both themes, saved preferences, table colouring, pitch/table display, sort reversal, pagination, player navigation and Team ID validation. The contrast report covers 18 shared text/control token combinations. This is not a claim of a full accessibility audit.

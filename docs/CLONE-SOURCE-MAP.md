## 1. Source-of-Truth Hierarchy

1. **Primary Data, Player/Club Images, and All Math & Business Logic**: Connected repository `mukudahal/FPLVORTEX` (baseline `main` commit `e6eea415bff9e452f39a19894b481b24da51f341`). Whenever the repository and the uploaded UI bundle conflict on data, IDs, images, or formulas, **`mukudahal/FPLVORTEX` wins**.
2. **Graphics, Design System, and 6-Page Shell**: `brand-kit/` (`design-tokens.css`, `design-tokens.json`, `BRAND-KIT.md`, `brand-preview.html`, self-hosted `InterVariable.woff2`, SVG marks/icons/patterns, dark/light tokens, glass panels, responsive shell). `brand-kit/assets/website-preview.html` is used strictly as a visual layout reference, **never** as a data or math source.
3. **Live Supplement + Offline Fallback**:
   - **Tier 1 (Authoritative Repo Data)**: `3_data_third_party/fplcopilot-projections-gw7-2026-10-15-v4.csv` (667 players, 20 clubs, GW7–GW16 `xmins` & `xpts`), `site/ui/videos.json` (30 `@FPLVORTEX` videos), Manager Entry `145784` (`FPLVORTEX` verified across `2_notebooks/*.ipynb`, `9_dashboard_reference/dashboard-reference-{1,2}.png`, and `6_replica_docs/screens/S01-transfer-planner.png`), and `VX_WC_VERIFIED_EVIDENCE_JSON` news/match notes.
   - **Tier 2 (Live Official FPL API Pipeline)**: `https://fantasy.premierleague.com/api/{bootstrap-static,fixtures,entry/145784,leagues-classic/...}` as implemented in `1_APP_dashboard/src/server/fplData.ts` and `site/worker/handler.js`, merged underneath Tier 1 repo projections so live status/codes/fixtures/standings enrich the repo dataset when reachable.
   - **Tier 3 (Explicitly Labelled Last-Resort Offline Fallback)**: `public/data/fpl-snapshot.json` is retained **only** to supply supplementary fields not stored in the CSV (`code` for official PL headshots, `team.code` for club badges, 380-fixture schedule, and cumulative season counts) when `fantasy.premierleague.com` is unreachable offline. Bundle example IDs (`5112705`) are removed from primary defaults in favor of repository Entry `145784` (`FPLVORTEX`). Synthetic demo files (`1_APP_dashboard/scripts/reporting/sample-report.json`, `site/ui/app.js` `sampleData()`) are excluded from runtime data.

## 3. Six-Route Feature Architecture

1. **`Command center` (`/`)** — Home hub for Entry `145784` (`FPLVORTEX`): GW8 Starting XI & bench pitch with real PL headshots, captaincy ranking (`rankCaptaincy`), transfer/roll verdict (`optimizePlan`), EO threats (`rankPlayerThreats`), `@FPLVORTEX` video feed (`site/ui/videos.json`), and verified club/international notes.
2. **`Squad optimizer` (`/optimizer`)** — Full Team Planner + **FPLReview-style Multi-GW Transfer & Chip Strategy Simulator**:
   - Interactive 15-man squad & transfer planner with clickable multi-column sorting (`Repo xPts`, `Opta xP`, `5-GW Fixture Score`, `Price`, `EO%`, `Minutes`), budget/3-per-club validation, and 0FT Roll vs 1FT vs 2FT (`-4` hit) comparison (`bankedTransferValueNextGw`).
   - **FPLReview-grade Chip EV Matrix & Horizon Planner** (`Wildcard`, `Free Hit`, `Bench Boost`, `Triple Captain` simulated across every upcoming GW with half-season chip rules `GW<=19` / `GW20..38`, optimal chip squad preview, and `searchPlanningHorizon` multi-week rollout).
   - **Paired 3,000-Draw Monte Carlo Distribution** (`runMonteCarlo`: Hold vs 1FT vs 2FT vs Peak Wildcard `mean`, `median`, `P10`, `P90`, and `Win % vs Hold`).
3. **`Player lab` (`/players`)** — Complete 667-player repository stats & projection explorer (`3_data_third_party/fplcopilot-projections-gw7-2026-10-15-v4.csv` + `computePlayerXPts` + `Opta xP`), position/club/price/minutes filters, real official PL player portraits (>=10 visible simultaneously with graceful fallback), side-by-side player comparison radar/breakdown, and GW7–GW16 horizon trajectory.
4. **`Fixture matrix` (`/fixtures`)** — 20-club multi-GW ticker powered by `buildStrengths` & `projectMatch` (`API_BASE=1100`, `HOME_GOALS=1.55`, `AWAY_GOALS=1.25`), attack/clean-sheet/overall modes, Poisson scoreline & CS% calculator, and club crest badges.
5. **`League intel` (`/leagues`)** — Mini-league standings, live EO & rank-impact calculator (`computeRankImpacts`, `captainDecision`, `rankPlayerThreats`, `feasibleMustOwnTargets`), and rival differential matrix centered on Entry `145784`.
6. **`Model & automation` (`/model`)** — Transparent mathematical specification (`computePlayerXPts`, 2026/27 `DEFCON` rules, `estimateMinutesDistribution`, `fitPointsCalibration`, `validateHistoricalPredictions` Brier/MAE/RMSE), data provenance status (Repo CSV + Live FPL API + Offline Snapshot fallback), snapshot refresh controls, and `@FPLVORTEX` briefing archive.

# Contributing

1. Fork or clone the repository.
2. Run `npm ci` and `npm run dev`.
3. Create a focused branch for your change.
4. Add or update tests for model, optimizer, normalizer or fixture behavior.
5. Run `npm run check` before opening a pull request.
6. Keep public FPL requests rate-limited and never add credentials to the client.

Commit messages follow Conventional Commits, for example `feat(model): add fixture swing weighting`.
